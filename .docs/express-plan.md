# Экспресс-план реализации MVP

## Цель
Запустить минимальный Telegram-бот на aiogram для ручного трекинга времени с четырьмя фиксированными категориями, хранением в PostgreSQL и простой агрегированной статистикой (проценты по категориям за период).

## Этапы и сроки (solo + ИИ)
1. **Инициализация (0.5 дня)**: обновить env-пример, описать конфиг БД (infra), базовая структура bot/logic/infra, подключить зависимости.
2. **Схема данных (0.5 дня)**: модель пользователя, сессии таймеров, миграция/DDL, базовые repo-методы.
3. **Логика таймеров (1 день)**: сценарии старт/стоп с исключением пересечений, сохранение сессий, расчёт агрегатов (проценты по категориям за период).
4. **Интерфейс бота (0.5 дня)**: команды/кнопки для четырёх категорий, ответы на английском, команда для вывода статистики.
5. **Тесты и прогоны (0.5 дня)**: юнит-тесты логики таймеров/агрегации, короткий ручной прогон бота с локальной БД.
6. **Обвязка и документы (0.5 дня)**: короткая инструкция по запуску, README/CHANGELOGE обновление, проверка `.docs`.

**Итого:** ~3-4 дня фокусной работы.

## Ресурсы и инструменты
- aiogram, PostgreSQL, миграции (любое лёгкое решение или простые SQL-скрипты).
- Локальный запуск/отладка, минимальная логирование/метрики.
- Документация в `.docs/` + README с командами запуска/миграций.

## Допущения и риски
- Один разработчик, доступен Telegram bot token и инстанс PostgreSQL.
- Нужна только текстовая статистика без экспорта; изменений в требованиях по категориям не ожидается.
- Риск задержек: настройка окружения/БД или поломки токена бота; смягчается через чек-лист запуска.
